BYEOLDAM · support

New experiment → enter a question → save three cards → continue the draft → write an interpretation, counter-perspective, action and options → start → review the outcome. Use Backup and restore in Settings to save or import JSON. Existing IDs are never overwritten. Invalid backups and corrupted originals are not automatically deleted. The card map shows recorded appearances, not probabilities or scores. Historical orders and PDFs are in Previous letters in Settings. New experiments do not offer paid purchases or automatic book delivery. For a past order issue, email only the order number and issue. Never send passwords or card numbers.
