주문 메일은 어떻게 보내나요?

iPhone의 Mail 앱에 이메일 계정을 설정해 주세요. 앱에서 Apple 결제를 확인한 뒤 편지함의 해당 주문에서 주문 메일을 열고 보내기를 누릅니다. 메일에는 선택한 주제·카드·질문 답변과 결제 확인용 JSON 첨부 파일이 포함됩니다. 메일 발신함에 들어간 것과 실제 수신은 다를 수 있으므로 접수 안내를 확인해 주세요. 취소하거나 전송에 실패하면 해당 주문에서 추가 결제 없이 다시 보낼 수 있습니다.

리딩은 어떤 내용인가요?

고민에 대한 추천 방향을 첫 장에서 먼저 읽고, 세 카드의 근거와 질문별 답, 선택지 비교, 판단을 바꿀 조건과 지금 할 행동을 살펴보는 구성입니다. 카드 선택에서는 덱을 섞고 세 장을 직접 고르면 선택한 카드가 뒤집힙니다. 해석은 입력한 정보와 카드의 상징에 따른 추천이며 실제 미래나 상대의 마음을 확인한 사실은 아닙니다.

PDF는 언제 받나요?

운영자가 주문 메일을 실제로 접수한 시점부터 6시간 이내에 제작·검토한 PDF를 수신 이메일로 전달합니다. 작은 별 편지는 10쪽, 깊은 별 이야기는 25쪽입니다. 리딩 제작에 AI를 활용하며 사람의 실시간 상담 서비스는 아닙니다.

어떤 언어로 받을 수 있나요?

한국어·영어·일본어·중국어 간체를 지원합니다. 주문 전에 설정에서 언어를 고르고 주문 확인의 PDF 언어를 확인해 주세요. 주문 후 앱 언어를 바꿔도 기존 주문의 PDF 언어는 유지됩니다.

편지함에 PDF를 넣고 싶어요.

이메일 첨부 PDF를 iPhone의 파일 앱에 저장한 후, 별담 편지함에서 해당 주문을 열어 PDF 가져오기를 선택합니다. 전달된 주문 번호가 포함된 파일 이름을 유지해 주세요. 예: 별담-주문UUID.pdf. 앱은 해당 주문 번호와 페이지 수를 확인합니다. 샘플 PDF로는 유료 주문을 완료할 수 없습니다.

앱을 지우거나 기기를 바꾸면 어떻게 되나요?

주문·마음 노트·가져온 PDF는 기기에 저장되며 자동 동기화나 다른 기기 자동 복원을 지원하지 않습니다. 받은 이메일과 PDF를 별도로 보관해 주세요. 결제 확인이 진행 중이면 편지함의 구매 복구를 사용해 주세요. 소비형 상품의 완료된 구매를 다시 결제하지 말고 주문 번호로 고객지원에 문의해 주세요.

지연·중복 주문·환불 문의

주문 번호, 상품명, 문제가 발생한 시각을 알려 주세요. 비밀번호·카드번호·주민등록번호는 보내지 마세요. 접수 후 약속한 시간이 지나면 먼저 메일의 스팸함과 발신함을 확인한 뒤 문의해 주세요. 환불 신청은 Apple 문제 신고에서 진행하며 Apple이 처리·결정합니다.

내 기록을 삭제하고 싶어요.

마음 노트는 앱에서 개별 삭제할 수 있습니다. 설정의 기기 데이터 삭제는 주문 처리·결제 확인이 남아 있으면 제한됩니다. 운영자에게 이미 보낸 이메일 내용의 열람·정정·삭제는 고객지원 주소로 요청해 주세요. 앱의 삭제와 운영자·고객 메일 사본의 삭제는 별개입니다.
